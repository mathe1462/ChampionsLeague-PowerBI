### Como criar o board de verdade no GitHub

1. Vá até o repositório → aba **Projects** → **New project** → template **Board**.
2. Renomeie as colunas padrão para **To do**, **Doing**, **Done**.
3. Clique em **Add item** em "To do" e cole cada linha do checklist acima como um card.
4. Conforme for avançando, arraste os cards entre as colunas.
5. Copie o link da URL do board e cole no README, na seção "Acompanhamento do Projeto".
